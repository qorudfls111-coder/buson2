아이온2 성역 파티 배치

포스 인원의 본캐·부캐 직업과 전투력을 넣으면 무스펠·비탄의 설원 성역 파티를 라운드별로 자동으로 나눠줍니다. 탱커·치유 같은 필수 역할을 먼저 채우고, 결과는 라운드마다 한 번에 복사해 게임 채팅창에 바로 붙여넣을 수 있습니다.

성역 파티 배치 사용하기 BUSON2 메인으로

라운드 자동 나누기

본캐 1개 + 부캐 N개면 N+1라운드로 나누고, 같은 사람의 캐릭터는 라운드마다 하나씩만 배치합니다.

필수 역할 먼저

1파티에는 탱커(수호성·검성)와 치유성을, 2파티 첫 자리에는 살성 → 검성 → 권성 순으로 우선 배치합니다.

호법성 분산 · 전투력

같은 라운드에 호법성이 2명 이상이면 양쪽에 나누고, 남은 부캐는 두 파티 전투력 합이 비슷해지도록 채웁니다.

채팅창용 복사

라운드 전체 복사 한 번이면 닉네임이 짧게 줄어든 "무스 // 강철 // …" 형식으로 복사돼 채팅창에 바로 붙여넣을 수 있습니다.

HOW TO

성역 파티 배치 사용법

10명 포스가 본캐와 부캐 2개씩 30캐릭터를 3라운드로 나누는 경우를 예로 들면, 입력은 한 번만 하고 계산은 버튼 하나로 끝납니다.

1

성역 고르기

무스펠 또는 비탄의 설원 탭을 고릅니다. 성역마다 입력한 명단이 따로 저장됩니다.

2

인원 · 부캐 수

포스 인원 수(2~30명)와 1인당 부캐 수(0~5개)를 정하면 입력칸과 라운드 수가 맞춰집니다.

3

명단 입력

사람마다 본캐·부캐의 닉네임, 직업, 전투력을 넣습니다. 입력한 명단은 브라우저에 자동 저장돼 다음 주에 그대로 씁니다.

4

계산 · 복사

최적 파티 배치 계산하기를 누르면 라운드별 1·2파티가 나옵니다. 라운드 전체 복사로 게임 채팅창에 붙여넣으면 공지 끝입니다.

배치 규칙 — 라운드 나누기

모든 조건을 동시에 만족하는 배치가 없을 때도 있어서, 아래 순서대로 최대한 맞춥니다. 한 사람의 캐릭터는 라운드마다 하나만 들어갑니다.

  1. 본캐를 라운드마다 고르게 나눕니다. 탱커 본캐와 치유성 본캐가 먼저, 그 역할이 가장 적은 라운드로 들어갑니다.
  2. 탱커·치유성 부캐를 그 역할이 부족한 라운드에 넣습니다.
  3. 남은 캐릭터는 전투력 합이 가장 낮은 라운드부터 채웁니다.

배치 규칙 — 1파티 · 2파티 나누기

  1. 1파티 1번 자리는 탱커(수호성·검성)입니다. 본캐 탱커가 있으면 본캐를 씁니다.
  2. 2파티 1번 자리는 딜러로, 살성 → 검성 → 권성 순이며 부캐가 있으면 부캐를 먼저 씁니다.
  3. 본캐 수호성이 1파티 탱커를 맡았는데 같은 라운드에 부캐 수호성이 있으면 2파티로 보냅니다.
  4. 치유성은 1파티에 1명 필수, 2파티에는 있으면 1명(부캐 우선)을 넣습니다.
  5. 호법성이 2명 이상이면 한쪽에 몰리지 않게 양쪽 파티에 나눕니다.
  6. 남은 본캐는 1파티부터 채우고, 남은 부캐는 전투력이 높은 순서로 합이 낮은 파티에 넣어 균형을 맞춥니다.

파티 안 자리 순서는 1번 탱커(2파티는 딜러) → 2~3번 → 4번 호법성 → 5번 치유성입니다. 결과 화면에서 파티마다 탱커·치유 충족 여부(✅ / ⚠️)와 전투력 합계를 함께 보여줍니다.

배치 예시 (가상 닉네임 10명 · 3라운드 중 1라운드)

5번치유의손 · 치유성 · 1,074k빛의치유 · 치유성 · 845k (부)

본캐 수호성(무스펠정복)이 1파티 탱커를 맡아서 같은 라운드의 부캐 수호성(방패셔틀)은 2파티로 갔습니다. 본캐는 1파티부터 채우기 때문에 1파티 전투력 합이 더 높게 나옵니다.

이 라운드를 라운드 전체 복사하면 아래처럼 복사됩니다. 1파티 5명 다음에 2파티 5명 순서입니다.

무스 // 강철 // 바람 // 셋째 // 치유 // 그림자 // 치유 // 권법왕 // 방패 // 빛의

닉네임은 3글자 이하면 그대로, 4글자 이상이면 앞 2글자만 남기고, [서버명] 표시는 지웁니다. 채팅 한 번에 라운드 전체를 보낼 수 있도록 줄인 형식입니다.

FAQ

성역 파티 배치 자주 묻는 질문

Q1 인원이 10명이 아니어도 되나요? ⌄
네. 포스 인원은 2~30명, 1인당 부캐는 0~5개까지 정할 수 있습니다. 라운드 수는 본캐 1개 + 부캐 수로 자동으로 정해지고, 라운드 인원이 홀수면 1파티가 한 명 더 많게 나눕니다.
Q2 탱커나 치유성이 없는 라운드는 어떻게 되나요? ⌄
탱커·치유성 캐릭터를 먼저 라운드마다 나눠 넣기 때문에 가능한 한 모든 라운드에 들어갑니다. 그래도 인원이 모자라면 해당 파티 제목에 ⚠️ 표시가 붙으니, 직업 입력을 확인하거나 부캐 구성을 바꿔 다시 계산해보세요.
Q3 왜 1파티 전투력이 더 높게 나오나요? ⌄
필수 역할을 배치한 뒤 남은 본캐를 1파티부터 채우기 때문입니다. 남은 부캐는 두 파티 전투력 합이 비슷해지도록 나누므로, 본캐가 적은 라운드일수록 두 파티가 비슷해집니다.
Q4 복사한 결과는 어디에 붙여넣나요? ⌄
게임 채팅창(포스 채팅 등)에 바로 붙여넣을 수 있도록 닉네임을 짧게 줄여 한 번에 보낼 수 있게 만듭니다. 디스코드나 메신저에 붙여넣어도 그대로 보입니다.
Q5 입력한 명단은 어디에 저장되나요? ⌄
지금 쓰는 브라우저에만 저장되며 서버로 보내지 않습니다. 무스펠과 비탄의 설원 명단이 따로 저장되고, 다른 기기나 브라우저에서는 다시 입력해야 합니다.
