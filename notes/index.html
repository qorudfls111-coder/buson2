스펙 계산기 파티 버프를 인게임 툴팁 기준으로 다시 맞췄습니다

수호성 격앙이 너프된 뒤에도 스펙 계산기에는 예전 값(+40%)이 그대로 남아 있었습니다. 이용자분이 보내주신 툴팁으로 확인해보니 격앙의 파티 PVE 피해 증폭은 "5% + 레벨당 0.5%"라 Lv35에서 22.5%이고, 수호성은 격앙 효과를 1.5배로 올려주는 고결의 갑주를 항상 켜두기 때문에 33.75%로 넣었습니다.

치유성·호법성 버프도 같이 확인했습니다. 불패의 진언과 보호의 빛은 Lv25 기준 피해 증폭 22.5%·완벽 10%이고 서로 중복되지 않습니다. 파티 강타는 호법성 5%, 치유성 10%(보호의 빛 Lv25 특화 5% + 대지의 축복 5%)로 고쳤습니다. 치유성을 12%로 적어뒀던 건 잘못된 값이었습니다.

그리고 "파티 강타"와 "파티 피해증폭"을 따로 고르던 칸을 힐러 버프(호법성/치유성)와 수호성 버프로 나눠서, 직업을 고르면 완벽, 치명타 피해 증폭, 질풍의 권능·대지의 축복의 공격력까지 한꺼번에 계산에 들어가도록 바꿨습니다. 예전에 저장해둔 스펙은 불러올 때 새 기준으로 자동으로 바뀝니다.

예전 사이트를 통째로 복사해 두었던 /sub/ 페이지는 부캐 버스 소개 페이지로 정리했습니다. 계산기는 이제 메인 한 곳에서만 관리해서 페이지마다 값이 달라지는 일이 없게 했습니다.

캐릭터 검색과 캐릭터 비교를 만들었습니다

닉네임만 알면 서버를 몰라도 전체 서버에서 캐릭터를 찾을 수 있게 했고, 상세 화면에서 장비, 스킬 레벨, 데바니온 보드 개방 현황, 칭호, 펫·날개까지 볼 수 있습니다. 두 캐릭터를 나란히 놓고 보는 캐릭터 비교 탭도 같이 추가했습니다.

검색한 캐릭터는 스펙 계산기와 아르카나 계산기로 바로 불러올 수 있습니다. 처음에는 피해 증폭·강타 같은 % 스탯도 자동으로 채웠는데, 게임 스탯창과 비교해보니 스킬 패시브·펫·날개 효과가 공식 정보에 없어서 실제보다 낮게 나왔습니다. 그래서 % 스탯은 자동 입력 대신 출처별 참고표로만 보여주도록 바꿨습니다.

아르카나 계산기도 기본 스킬 레벨 14를 스킬 포인트(0~10)와 데바니온(0~4)으로 나눠서 불러온 캐릭터의 실제 스킬 레벨과 맞게 했고, 부족한 스킬을 채울 카드를 추천할 때 이미 스킬 레벨 4로 꽉 찬 카드는 빼도록 고쳤습니다.

기사 조회 기능에는 원래 "문제 제보 TOP 10"이라는 순위가 있었습니다. 제보 건수가 많은 캐릭터를 위에서부터 보여주는 방식이었는데, 만들어 놓고 보니 마음에 걸리는 부분이 있었습니다. 제보는 이용자가 직접 등록하는 내용이라 사실 여부를 확인할 방법이 없는데, 그걸 순위로 매겨서 누구나 볼 수 있게 노출하면 실제로 문제가 없던 사람도 악의적인 제보 몇 번으로 "TOP 10 사기꾼"처럼 낙인 찍힐 수 있겠다는 생각이 들었습니다.

그래서 공개 순위는 없애고, 거래하려는 기사 아이디를 직접 검색했을 때만 그 기사의 정상 거래·문제 제보 건수를 확인할 수 있도록 바꿨습니다. 원래 하려던 "버스 타기 전에 확인하는 용도"는 그대로 유지되면서, 불특정 다수에게 이름이 순위로 노출되는 부분만 없앤 겁니다. 대신 평가가 3건 이상 쌓인 기사에는 신뢰 배지를 붙여서, 데이터가 있는 경우엔 오히려 더 잘 보이게 했습니다.

본부 계산기에 던전별 오드 효율 순위를 직접 계산해서 넣었습니다

본부(파밍) 계산기를 쓰다 보면 "그래서 지금 어떤 던전을 도는 게 제일 이득이지?"라는 질문이 항상 남더라고요. 계산기 자체는 던전 하나를 골라서 계산하는 용도라 여러 던전을 한눈에 비교하긴 어려웠습니다.

그래서 계산기에 등록된 던전별 기본 키나와 소비 오드를 전부 정리해서, 오드 1개당 획득 키나를 직접 계산해봤습니다. 결과가 꽤 재미있었는데, 무스펠(어려움)이 오드당 75,000키나로 다른 던전보다 확실히 효율이 높게 나왔고, 1~2단계 던전들은 진입은 쉬운 대신 오드 효율은 상대적으로 낮은 편이었습니다. 던전별 순위는 던전 파밍 DB에서 오드 효율순으로 정렬해 볼 수 있습니다. 다만 이건 순수 키나 기준이라 판당 소요 시간이나 재료 보상은 안 들어가 있어서, 실제 파밍 순서는 본인 클리어 시간 기준으로 계산기에서 한 번 더 확인해보시는 걸 추천합니다.

사이트를 점검하다가 발견한 건데, `/driver/` 페이지가 실제로는 내용이 하나도 없고 메인 페이지의 버스 기사 탭으로 리다이렉트만 하는 껍데기였습니다. 예전에 사이트 구조를 바꾸면서 남은 흔적 같은데, 검색 결과에는 노출될 수 있는 주소인데 막상 들어가면 아무것도 없었던 셈이라 방문자 입장에서도, 검색 노출 입장에서도 안 좋은 상태였습니다.

그래서 이 페이지를 실제 버스 기사 계산기 설명 페이지로 새로 만들었고, 던전·파밍 DB(/dungeon/), 파밍 비교(/compare/) 페이지도 같이 새로 만들었습니다. 원래 메인 페이지 안에서 탭으로만 볼 수 있던 기능들인데, 각자 따로 주소를 가진 페이지로 분리했습니다.
